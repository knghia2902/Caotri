# Plan 03-01: Category Management & Modal CRUD

## Objective
Xây dựng module Quản lý Danh mục sản phẩm (`/admin/categories`): Tạo tiện ích tạo slug SEO tiếng Việt `src/lib/slugify.ts`, Server Actions `src/app/actions/category.ts` (CRUD danh mục), component Modal Dialog thêm/sửa danh mục, và giao diện bảng quản trị Clean Tech hiển thị đầy đủ thông tin danh mục và số lượng sản phẩm liên kết.

## Context
- Đọc `.planning/phases/03-admin-catalog-content-management/03-CONTEXT.md`.
- Đọc `.planning/phases/03-admin-catalog-content-management/03-RESEARCH.md`.
- Kế thừa `src/lib/prisma.ts` và `src/lib/auth.ts` (`requireRole`).

## Must Haves
- D-05: Quản lý Danh mục (`/admin/categories`): Bảng Clean Tech kết hợp Modal Dialog Thêm / Sửa nhanh ngay trên trang danh sách.

<task type="lib">
  <name>Tạo hàm tiện ích sinh slug tiếng Việt chuẩn SEO (src/lib/slugify.ts)</name>
  <read_first>
    - src/lib/utils.ts
  </read_first>
  <action>
    Tạo file `src/lib/slugify.ts` chứa hàm `slugify(text: string): string`:
    - Chuyển đổi toàn bộ chữ cái tiếng Việt có dấu thành không dấu (đ -> d, à, á, ả, ã, ạ, â, ấ, ...).
    - Chuyển thành chữ thường, thay khoảng trắng và ký tự đặc biệt thành dấu gạch ngang `-`.
    - Xóa các dấu gạch ngang liên tiếp hoặc ở đầu/cuối chuỗi.
  </action>
  <acceptance_criteria>
    - `slugify("Bàn phím cơ DareU EK87")` trả về `"ban-phim-co-dareu-ek87"`.
    - `slugify("Chuột Gaming Không Dây")` trả về `"chuot-gaming-khong-day"`.
  </acceptance_criteria>
  <verify>
    Chạy lệnh test nhanh qua Node.js hoặc trong script kiểm thử.
  </verify>
</task>

<task type="action">
  <name>Xây dựng Server Actions Quản lý Danh mục (src/app/actions/category.ts)</name>
  <read_first>
    - src/lib/prisma.ts
    - src/lib/auth.ts
    - src/lib/slugify.ts
  </read_first>
  <action>
    Tạo file `src/app/actions/category.ts`:
    - `createCategory(data)`: Kiểm tra `requireRole(['ADMIN', 'STAFF'])`. Tự động sinh `slug` nếu chưa có bằng `slugify`. Tạo bản ghi trong Prisma bảng `Category`. Gọi `revalidatePath('/admin/categories')` và `revalidatePath('/')`.
    - `updateCategory(id, data)`: Kiểm tra quyền, cập nhật tên, slug, image, order. Revalidate paths.
    - `deleteCategory(id)`: Kiểm tra quyền `requireRole(['ADMIN', 'STAFF'])`. Kiểm tra xem danh mục có sản phẩm liên kết hay không. Nếu có sản phẩm, cảnh báo không cho xóa; nếu không có sản phẩm, thực hiện xóa. Revalidate paths.
  </action>
  <acceptance_criteria>
    - Server Actions khai báo `'use server'`.
    - Xử lý lỗi trùng lặp slug hoặc danh mục có sản phẩm liên kết.
  </acceptance_criteria>
  <verify>
    Biên dịch không có lỗi TypeScript.
  </verify>
</task>
