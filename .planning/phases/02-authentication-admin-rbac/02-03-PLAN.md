# Plan 02-03: Admin Dashboard Layout, Collapsible Sidebar & RBAC Guard

## Objective
Xây dựng khung giao diện quản trị responsive toàn diện (`src/app/admin/layout.tsx`): thanh điều hướng Sidebar có khả năng thu gọn (260px $\leftrightarrow$ 64px icon-only trên desktop, mobile drawer), Top Header với breadcrumbs, liên kết ra Storefront, badge hiển thị vai trò (ADMIN / STAFF), nút đăng xuất; đồng thời triển khai phân quyền 2 lớp (RBAC Guard) ở cả giao diện Sidebar và Server Action helper `requireRole`.

## Context
- Đọc `.planning/phases/02-authentication-admin-rbac/02-CONTEXT.md`.
- Đọc `.planning/phases/02-authentication-admin-rbac/02-RESEARCH.md`.
- Kế thừa session payload và auth helpers từ Plan 02-01 và 02-02.

## Must Haves
- D-05: Sidebar điều hướng có thể thu gọn (Collapsible Sidebar).
- D-06: Header trên cùng (Top bar) đầy đủ tiện ích: breadcrumbs, xem shop, user info & role badge, logout.
- D-07: Quy tắc phân quyền chi tiết: ADMIN toàn quyền, STAFF xem & xử lý đơn hàng và sản phẩm/danh mục.
- D-09: Bảo mật 2 lớp (Defense-in-Depth) kết hợp UI lọc menu, Middleware và Server Action requireRole.

<task type="security">
  <name>Bổ sung hàm helper requireRole chặn ở tầng Server Actions</name>
  <read_first>
    - src/lib/auth.ts
    - src/types/index.ts
  </read_first>
  <action>
    Cập nhật `src/lib/auth.ts` bổ sung các hàm kiểm soát phân quyền backend:
    - `requireAuth()`: Lấy session hiện tại, ném lỗi `Unauthorized` nếu chưa đăng nhập.
    - `requireRole(allowedRoles: UserRole[])`: Kiểm tra session hiện tại, nếu `role` của user không nằm trong `allowedRoles` -> ném lỗi `Forbidden: Quyền truy cập không hợp lệ`.
    - Cập nhật script `scripts/test-auth.ts` để kiểm thử cả logic của `requireRole` cho cả hai vai trò ADMIN và STAFF.
  </action>
  <acceptance_criteria>
    - `requireRole(['ADMIN'])` cho phép user Admin và từ chối user Staff.
    - Script `scripts/test-auth.ts` kiểm thử logic này thành công.
  </acceptance_criteria>
  <verify>
    Chạy `npx tsx scripts/test-auth.ts`.
  </verify>
