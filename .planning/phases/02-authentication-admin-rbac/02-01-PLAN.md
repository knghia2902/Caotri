# Plan 02-01: Core Auth Library & Session Infrastructure

## Objective
Cài đặt thư viện `jose` và `sonner`, xây dựng module bảo mật lõi `src/lib/auth.ts` (JWT signing, verification, cookie management) và Server Actions xác thực `src/app/actions/auth.ts` (login, logout, get current user) kết hợp bcrypt kiểm tra mật khẩu tài khoản quản trị.

## Context
- Đọc `.planning/phases/02-authentication-admin-rbac/02-CONTEXT.md`.
- Đọc `.planning/phases/02-authentication-admin-rbac/02-RESEARCH.md`.
- Đọc `src/types/index.ts` và `prisma/schema.prisma`.

## Must Haves
- D-01: Sử dụng Custom JWT Session với thư viện `jose` và Cookie httpOnly (secure, sameSite: 'lax').
- D-02: Thời hạn phiên đăng nhập 7 ngày sliding session.

<task type="lib">
  <name>Xây dựng module xác thực JWT và Cookie session (src/lib/auth.ts)</name>
  <read_first>
    - .planning/phases/02-authentication-admin-rbac/02-CONTEXT.md
    - .planning/phases/02-authentication-admin-rbac/02-RESEARCH.md
    - src/types/index.ts
  </read_first>
  <action>
    Tạo file `src/lib/auth.ts`:
    - Định nghĩa `SessionPayload` gồm: `userId`, `email`, `name`, `role` (`UserRole`).
    - Viết hàm `signJWT(payload)` sử dụng `jose.SignJWT` với thuật toán HS256, thời hạn 7 ngày, ký bằng `JWT_SECRET` (fallback secret an toàn nếu thiếu biến môi trường).
    - Viết hàm `verifyJWT(token)` sử dụng `jose.jwtVerify` để giải mã và xác thực token, trả về `SessionPayload` hoặc `null` nếu không hợp lệ hoặc hết hạn.
    - Viết helper `setSessionCookie(token)` và `clearSessionCookie()` thao tác với `cookies()` từ `next/headers` (đặt cờ `httpOnly: true`, `secure: process.env.NODE_ENV === 'production'`, `sameSite: 'lax'`, `path: '/'`, `maxAge: 7 * 24 * 60 * 60`).
    - Viết hàm `getCurrentSession()` đọc cookie và trả về payload đã verify.
  </action>
  <acceptance_criteria>
    - `src/lib/auth.ts` xuất đầy đủ: `signJWT`, `verifyJWT`, `setSessionCookie`, `clearSessionCookie`, `getCurrentSession`.
    - Không import các module Node-only trong code dùng cho Edge middleware.
  </acceptance_criteria>
  <verify>
    Tạo script kiểm thử đơn vị hoặc test verify token thành công.
  </verify>
</task>

<task type="action">
  <name>Tạo Server Actions đăng nhập và đăng xuất (src/app/actions/auth.ts)</name>
  <read_first>
    - src/lib/auth.ts
    - src/lib/prisma.ts
  </read_first>
  <action>
    Tạo file `src/app/actions/auth.ts`:
    - `loginAction(prevState, formData)`: Nhận email và password từ formData, kiểm tra hợp lệ với Zod. Tìm user trong cơ sở dữ liệu qua `prisma.user.findUnique({ where: { email } })`. So sánh mật khẩu bằng `bcrypt.compare`. Nếu chính xác: ký JWT và gọi `setSessionCookie(token)`, trả về `{ success: true, user: { id, email, name, role } }`. Nếu thất bại: trả về `{ success: false, error: 'Email hoặc mật khẩu không chính xác' }`.
    - `logoutAction()`: Gọi `clearSessionCookie()` và chuyển hướng về `/admin/login`.
    - `getCurrentUserAction()`: Trả về thông tin user từ session hiện tại.
  </action>
  <acceptance_criteria>
    - `src/app/actions/auth.ts` khai báo `'use server'`.
    - `loginAction` xử lý cả trường hợp email không tồn tại, mật khẩu sai và đăng nhập thành công.
    - `logoutAction` xóa cookie `caotri_session`.
  </acceptance_criteria>
  <verify>
    Chạy `npx tsx scripts/test-auth.ts` kiểm thử logic xác thực.
  </verify>
</task>
