# Plan 02-02: Edge Middleware & Split-Screen Login Page

## Objective
Thiết lập Next.js Edge Middleware (`src/middleware.ts`) bảo vệ toàn diện các tuyến đường `/admin/*`, và xây dựng trang đăng nhập `/admin/login` phong cách Clean Tech với bố cục Split Screen 2 cột kèm nút 1-click Quick-fill demo credentials cho tài khoản Admin và Staff.

## Context
- Đọc `.planning/phases/02-authentication-admin-rbac/02-CONTEXT.md`.
- Đọc `.planning/phases/02-authentication-admin-rbac/02-RESEARCH.md`.
- Kế thừa `src/lib/auth.ts` và `src/app/actions/auth.ts` từ Plan 02-01.

## Must Haves
- D-03: Bố cục Split Screen 2 cột cho trang /admin/login.
- D-04: Tích hợp nút 1-click Quick-fill demo credentials cho Admin và Staff.
- D-08: Xử lý khi Staff vi phạm quyền: redirect về /admin?error=forbidden kèm Toast cảnh báo.

## Tasks

<task type="middleware">
  <name>Tạo Edge Middleware bảo vệ các route /admin/* (src/middleware.ts)</name>
  <read_first>
    - src/lib/auth.ts
    - .planning/phases/02-authentication-admin-rbac/02-RESEARCH.md
  </read_first>
  <action>
    Tạo file `src/middleware.ts`:
    - Cấu hình matcher cho `/admin/:path*`.
    - Bỏ qua route `/admin/login` và các file static.
    - Đọc cookie `caotri_session` từ request. Nếu không có cookie -> chuyển hướng về `/admin/login?redirect={encodedPath}`.
    - Sử dụng hàm `verifyJWT(token)` giải mã token:
      - Nếu token không hợp lệ hoặc hết hạn -> xóa cookie và chuyển hướng về `/admin/login`.
      - Nếu token hợp lệ và truy cập `/admin/login` -> chuyển hướng về `/admin`.
      - Nếu `session.role === 'STAFF'` và người dùng truy cập các route cấm (`/admin/banners`, `/admin/settings`) -> chuyển hướng về `/admin?error=forbidden`.
  </action>
  <acceptance_criteria>
    - `src/middleware.ts` hoạt động trên Next.js Edge runtime.
    - Không thể truy cập `/admin` hoặc bất kỳ route con nào khi chưa đăng nhập.
    - Staff bị chặn và điều hướng kèm param `error=forbidden` khi vào URL cấm.
  </acceptance_criteria>
  <verify>
    Chạy `npm run build` xác nhận middleware biên dịch thành công mà không có lỗi runtime compatibility.
  </verify>
</task>
