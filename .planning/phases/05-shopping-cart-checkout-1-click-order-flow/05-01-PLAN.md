# Plan 05-01: Zustand Cart Store & Storefront Cart Integration

## Objective
Xây dựng Cart Store bằng Zustand với `persist` middleware lưu trữ an toàn trong `localStorage` (không gây lỗi Hydration mismatch giữa SSR và CSR). Tích hợp số lượng giỏ hàng trực tiếp lên Badge trên `StorefrontHeader`, và kết nối nút "Thêm vào giỏ hàng" tại `ProductActions` với Sonner Toast thông báo kèm nút "Xem giỏ hàng".

## Context
- Đọc `.planning/phases/05-shopping-cart-checkout-1-click-order-flow/05-CONTEXT.md`.
- Đọc `DESIGN.md` §16 (Cart) & §37 (UX Rules: Thêm vào giỏ phải phản hồi ngay, Cart icon hiển thị số lượng).
- Kế thừa `src/components/storefront/storefront-header.tsx`, `src/components/storefront/product-actions.tsx`.
- Thư viện `zustand` đã được cài đặt sẵn (`^5.0.3`).

## Must Haves
- D-03: Thêm giỏ hàng phản hồi bằng Sonner toast nhẹ nhàng kèm nút "Xem giỏ hàng" chuyển hướng sang `/cart`.
- D-04: Header Cart icon cập nhật số lượng realtime, có cờ `isMounted` để triệt tiêu lỗi Hydration.
- CART-01: Thêm sản phẩm vào giỏ từ trang chi tiết sản phẩm.
- CART-03: Tự động lưu giỏ hàng vào `localStorage` và tự động khôi phục khi F5 trang.

## Tasks

<task type="store">
  <name>Xây dựng Zustand Cart Store</name>
  <read_first>
    - package.json
    - src/types/index.ts
  </read_first>
  <action>
    Tạo tệp `src/stores/cart-store.ts`:
    - Định nghĩa interface `CartItem`:
      ```ts
      export interface CartItem {
        id: string; // productId
        name: string;
        slug: string;
        price: number;
        originalPrice?: number | null;
        image: string;
        quantity: number;
      }
      ```
    - State & Actions:
      - `items: CartItem[]`
      - `addItem(product: Omit<CartItem, 'quantity'>, quantity?: number): void` (nếu đã có thì cộng dồn số lượng)
      - `removeItem(productId: string): void`
      - `updateQuantity(productId: string, quantity: number): void` (nếu <= 0 thì xóa)
      - `clearCart(): void`
      - `getTotalItems(): number`
      - `getTotalPrice(): number`
    - Cấu hình `persist` middleware lưu vào `localStorage` với key `caotri_cart_storage`.
    - Tạo custom hook `useCartMounted()` hoặc export cờ `hasHydrated` để đảm bảo phía client render badge số lượng chính xác mà không gặp lỗi SSR Hydration mismatch.
  </action>
  <acceptance_criteria>
    - Zustand store hỗ trợ đầy đủ các thao tác: addItem, removeItem, updateQuantity, clearCart, getTotalItems, getTotalPrice.
    - Lưu trữ an toàn trong localStorage.
  </acceptance_criteria>
  <verify>
    Biên dịch TypeScript không lỗi: `npx tsc --noEmit`.
  </verify>
</task>
