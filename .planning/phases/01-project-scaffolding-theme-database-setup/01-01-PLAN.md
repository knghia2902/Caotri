# Plan 01-01: Next.js App Router Scaffolding & Clean Tech Theme Setup

## Objective
Khởi tạo cấu trúc dự án Next.js 14/15 App Router với TypeScript và Tailwind CSS, áp dụng phong cách thiết kế **Clean Tech Minimalist** (nền sáng tinh tế, tương phản cao, hiện đại như Keychron/Apple Tech) và xây dựng bộ UI component nguyên tử tái sử dụng cho toàn bộ dự án.

## Context
- Đọc `.planning/phases/01-project-scaffolding-theme-database-setup/01-CONTEXT.md` (Quyết định D-01, D-02).
- Đọc `GEMINI.md` về cấu trúc thư mục và quy chuẩn mã nguồn.

    - `npm run build` hoặc `npx next build` vượt qua kiểm tra cú pháp TypeScript.
  </acceptance_criteria>
  <verify>
    `npm run build` hoặc lệnh biên dịch Next.js hoàn thành không lỗi cú pháp.

<task type="ui">
  <name>Cấu hình Clean Tech Minimalist Theme và CSS Variables</name>
  <read_first>
    - .planning/phases/01-project-scaffolding-theme-database-setup/01-CONTEXT.md
    - tailwind.config.ts
  </read_first>
  <action>
    Cập nhật `tailwind.config.ts` và `src/app/globals.css` để định nghĩa bảng màu Clean Tech Minimalist:
    - Nền trắng/xám tối giản: `bg-slate-50` / `bg-white` với text `text-slate-900` và phụ trợ `text-slate-500`.
    - Điểm nhấn công nghệ (Accent): `primary` (slate-900), `accent` (cyan-600 hoặc blue-600 tinh tế), `border` (slate-200), `ring` (slate-400).
    - Tạo hàm tiện ích `cn()` trong `src/lib/utils.ts` kết hợp `clsx` và `tailwind-merge`.
  </action>
  <acceptance_criteria>
    - `src/lib/utils.ts` xuất hàm `cn(...inputs)`.
    - `src/app/globals.css` chứa các biến màu và quy chuẩn typography sạch sẽ.
    - `tailwind.config.ts` mở rộng bảng màu và cấu hình font, container chuẩn responsive.
  </acceptance_criteria>
  <verify>
    Kiểm tra file `src/lib/utils.ts` và kiểm tra `src/app/globals.css` được import trong `src/app/layout.tsx`.
  </verify>
</task>
