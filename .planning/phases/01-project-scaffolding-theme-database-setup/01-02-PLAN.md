# Plan 01-02: Prisma ORM Setup & Comprehensive E-Commerce Schema

## Objective
Cấu hình Prisma ORM với cơ sở dữ liệu SQLite cục bộ (`file:./dev.db`) phục vụ phát triển nhanh, thiết lập toàn bộ Schema quan hệ e-commerce (User, Category, Product, Order, OrderItem, Banner, SiteSetting) theo quyết định D-06, D-07 và tạo Prisma Client singleton chuẩn.

## Context
- Đọc `.planning/phases/01-project-scaffolding-theme-database-setup/01-CONTEXT.md` (Quyết định D-06, D-07 về SQLite trước, Supabase sau).
- Đọc `.planning/research/ARCHITECTURE.md` về mô hình schema Prisma và quan hệ giữa các bảng.

<task type="schema">
  <name>Thiết kế Prisma Schema hoàn chỉnh cho E-Commerce Gaming Gear</name>
  <read_first>
    - .planning/research/ARCHITECTURE.md
    - .planning/phases/01-project-scaffolding-theme-database-setup/01-CONTEXT.md
  </read_first>
  <action>
    Viết `prisma/schema.prisma` với provider `sqlite` (hỗ trợ chuyển `postgresql` khi deploy) bao gồm các bảng:
    - `User`: id, email (unique), password, name, role (ADMIN / STAFF), createdAt, updatedAt.
    - `Category`: id, name, slug (unique), description, imageUrl, orderIndex, createdAt, quan hệ `products`.
    - `Product`: id, name, slug (unique), description, price, originalPrice, images (lưu chuỗi JSON hoặc mảng URL), specs (chuỗi JSON lưu DPI, switch, trọng lượng...), inStock, isFeatured, isNew, categoryId, quan hệ `category`, `orderItems`.
    - `Order`: id, orderNumber (unique), customerName, customerPhone, customerAddress, customerNotes, totalAmount, status (PENDING, CONTACTED, SHIPPING, COMPLETED, CANCELLED), quan hệ `items`.
    - `OrderItem`: id, orderId, productId, name, price, quantity.
    - `Banner`: id, title, imageUrl, linkUrl, orderIndex, isActive, createdAt.
    - `SiteSetting`: key (id), value, updatedAt.
    Chạy `npx prisma db push` hoặc `npx prisma migrate dev` để đồng bộ cơ sở dữ liệu SQLite cục bộ `dev.db`.
  </action>
  <acceptance_criteria>
    - `prisma/schema.prisma` định nghĩa đầy đủ 7 models: User, Category, Product, Order, OrderItem, Banner, SiteSetting.
    - Lệnh `npx prisma db push` chạy thành công tạo file `prisma/dev.db`.
    - Lệnh `npx prisma generate` sinh ra Prisma Client TypeScript types thành công.
  </acceptance_criteria>
  <verify>
    Chạy `npx prisma validate` và `npx prisma generate` kiểm tra schema hợp lệ.
  </verify>
</task>
