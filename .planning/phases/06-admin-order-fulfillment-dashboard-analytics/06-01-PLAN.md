<task type="auto">
  <name>Task 3: Nâng cấp Trang Admin Dashboard với Stat Cards & Danh sách Đơn Mới</name>

  <action>
    - Cập nhật `src/app/admin/(dashboard)/page.tsx`:
      - Truy vấn đồng thời qua `Promise.all`:
        1. Doanh thu thực tế: `prisma.order.aggregate` sum `totalAmount` where `status = "COMPLETED"`.
        2. Doanh thu đang xử lý: sum `totalAmount` where `status in ["PENDING", "CONTACTED", "SHIPPING"]`.
        3. Số đơn mới cần xử lý: count where `status = "PENDING"`.
        4. Số sản phẩm trong kho: count where `inStock = true`.
        5. Đơn hàng trong 7 ngày gần nhất để truyền vào `computeDailyRevenue`.
        6. Danh sách 6 đơn hàng mới nhất: `take: 6, orderBy: { createdAt: "desc" }, include: { items: true }`.

        + Đơn mới cần xử lý (badge vàng, có link xem ngay).
